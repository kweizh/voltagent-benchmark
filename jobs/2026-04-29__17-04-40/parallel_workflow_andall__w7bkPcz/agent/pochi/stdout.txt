### Workflow design (`index.ts`)

```
createWorkflowChain
  └─ andThen  "prepare"            – trim / normalise the input string
  └─ andAll   "parallel-analysis"  – 4 branches run concurrently
       ├─ andThen  "word-count"         pure function, counts words
       ├─ andThen  "char-count"         pure function, counts characters
       ├─ andThen  "sentiment-analysis" calls sentimentAgent (gpt-4o-mini)
       └─ andThen  "keyword-extraction" calls keywordsAgent  (gpt-4o-mini)
  └─ andThen  "summarise"          – merges the tuple of parallel results
```

Key points:
- `andAll` receives a `steps` array marked `as const` so TypeScript infers the result as a precise 4-tuple `[{wordCount}, {charCount}, {sentimentResult}, {keywordsResult}]`.
- The `summarise` step destructures that tuple and builds the final Zod-validated result object.
- `run.ts` calls `parallelWorkflow.run(input)` then writes `output.json` and calls `process.exit(0)` to prevent VoltAgent's async resources from keeping the process alive.
