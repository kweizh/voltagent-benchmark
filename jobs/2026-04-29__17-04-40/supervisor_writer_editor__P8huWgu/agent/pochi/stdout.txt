```
Input: "The Future of AI"
        ↓
  [Writer Agent]  →  writes a 3–5 paragraph article
        ↓  { article: string }
  [Editor Agent]  →  improves grammar, clarity & tone
        ↓  { editedArticle: string }
  output.txt  ✓
```

### Key implementation details

- **Writer Agent** (`gpt-4o-mini`) — instructed to draft a clear, well-structured short article on the given topic.
- **Editor Agent** (`gpt-4o-mini`) — instructed to polish the draft for grammar, clarity, and professional tone; returns only the revised text.
- **`createWorkflowChain`** chains both agents sequentially:
  1. `.andAgent(task, writerAgent, { schema: z.object({ article: z.string() }) })` — the task function receives the workflow's input `{ topic }` and returns the prompt string.
  2. `.andAgent(task, editorAgent, { schema: z.object({ editedArticle: z.string() }) })` — the task function receives the writer's output `{ article }` and returns the editing prompt.
- The workflow `result` schema is `z.object({ editedArticle: z.string() })`, matching the editor's output schema directly.
- After `workflow.run({ topic: "The Future of AI" })`, `result.result.editedArticle` is written to `output.txt`, then `process.exit(0)` is called to terminate cleanly.
